01 — Tentang Saya

Ringkasan Profil

Full Stack Developer dengan pengalaman 8+ tahun dalam siklus pengembangan perangkat lunak (SDLC) lengkap: analisis kebutuhan, desain, coding, testing, hingga deployment dan pemeliharaan aplikasi web production di sektor korporat dan perbankan. Kuat di ekosistem PHP modern (Laravel dan CodeIgniter), perancangan dan pengamanan RESTful API, optimasi query MySQL/MariaDB, serta antarmuka HTML5, CSS3, JavaScript, dan Vue 3.

Terbiasa memelihara dan meng-upgrade sistem legacy, mengelola repository Git dengan alur branching dan code review, membangun pipeline CI/CD, serta deployment dengan Docker di server Linux. Menguasai Python untuk scripting, otomasi deployment, dan pembuatan API (FastAPI). Cepat mempelajari teknologi baru dan berpengalaman memimpin serta membimbing developer junior.
